## ⚡ Key Features
<a id="key-features"></a>
### Core Functionality
- **Multitrack Editing:** Edit multiple sound tracks simultaneously for complex audio projects.
- **Wide Format Support:** Compatible with WAV, MP2, MP3, AU, OGG, and AIFF.
- **Recording Capabilities:** Record audio from various sources like microphones and line inputs.
- **Essential Editing Tools:** Includes copy, crop, paste, replace, divide, and zoom functions.
- **Export Options:** Export your work in multiple formats including WAV and MP3 (using LAME).

### Advanced Features
- **Extensive Effects Library:** Apply effects like equalization, compression, and noise correction.
- **Metadata Editing:** Organize your audio files with an integrated metadata editor.
- **Audio Analysis Tools:** Utilize tools for rhythm detection and silence identification.
- **Spectrum Viewer:** Visualize audio frequencies for detailed analysis.
